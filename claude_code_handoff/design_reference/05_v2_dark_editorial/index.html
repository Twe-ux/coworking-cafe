— TOKEN tokens.css Variables CSS : palette (--main sauge, --btn miel, --body noir), typo Fraunces/Inter/JetBrains, classes utilitaires (nav, btn, card, chip, grid, section). tokens.css
— ICON icons.jsx Composant SVG unique `<Icon name size stroke />` · ~40 icônes line (home, calendar, clock, wallet, building, sparkle, check…). icons.jsx
— COMP shared.jsx Composants inter-pages : <Nav> avec burger mobile, <PageHeader> éditorial, <Footer> 4 colonnes, constantes BRAND + NAV_LINKS + SPACES. shared.jsx
Stack technique · React 18 + Babel inline · pas de bundler. Chaque page charge tokens.css, icons.jsx et shared.jsx puis son propre composant.
Responsive · grilles CSS avec clamp(), breakpoint navigation à 960px (nav desktop / burger mobile), breakpoint dashboard à 960px (sidebar fixe / drawer).
Navigation · liens relatifs entre pages via <a href="page.html">. La navbar masque automatiquement le lien actif (prop active).
À produire côté client · 4 photos des espaces, logo vectoriel définitif, 8-10 portraits équipe/partenaires. Toutes les photos sont actuellement représentées par des placeholders colorés.
